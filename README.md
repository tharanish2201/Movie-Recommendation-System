# Movie Recommendation System

## Overview
A content-based movie recommendation system built using Python and Scikit-Learn.

## Features
- Recommends similar movies based on genre and overview.
- Uses CountVectorizer for text vectorization.
- Uses Cosine Similarity for recommendation.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Google Colab

## Dataset
Movie dataset containing:
- Movie ID
- Title
- Genre
- Overview

## Workflow
1. Data Preprocessing
2. Feature Engineering
3. Vectorization using CountVectorizer
4. Similarity Calculation using Cosine Similarity
5. Recommendation Generation

## Example
Input:
Iron Man

Output:
Top 5 similar movies recommended by the model.
